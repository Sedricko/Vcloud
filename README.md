# Vcloud

Espaço virtual para Android: um app hospedeiro que roda o jogo **dentro dele**, para o motor do
[Unit](https://github.com/Sedricko/Unit) ler a memória do jogo **sem root** e sem o vPhoneOS.

Projeto de aprendizagem, só para jogos **offline single-player**.

- `PLANO.md`: o cronograma e onde estamos.
- `docs/pesquisa.md`: o que já foi pesquisado (Twoyi, BlackBox, VirtualApp).
- `.claude/skills/espaco-virtual/`: o contexto e as regras para quem continuar o projeto (pessoa ou agente).
